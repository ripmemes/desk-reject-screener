# desk-reject-screener
This repository implements a multi-stage triage pipeline that uses GenAI to automate academic desk rejection screening. To set it up, create a .env file with your OPEN_REVIEW_USERNAME, OPEN_REVIEW_PASSWORD, and API_KEY. To benchmark the system, simply run python components/evaluate.py. The suite finishes almost instantly because the LLM responses are already saved; only the performance metrics are recalculated. If you want to clear the saved progress and query the live LLM again, delete the eval_progress_checkpoint.json file. The terminal output prints the summary metrics first, followed by the specific diagnostic judgment for each error (the false positives and false negatives). Because this text stream is extremely long, it is highly recommended to dump the output straight into a file for review: python components/evaluate.py > output.txt.
